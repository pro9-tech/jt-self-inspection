# 다크모드, 그래프 툴팁, 레이아웃 개선 및 보고서 출력 연동 계획서

본 계획서는 자주검사 앱에 다크모드 도입, 차트 툴팁 추가, 반응형 레이아웃 겹침 해결, 로고 정렬 및 테마 컬러 수정, 그리고 보고서 인쇄 양식 변경 및 수치 데이터 개별 출력 연동을 수행하기 위한 계획입니다.

## 1. 주요 변경 및 개선 사항

### A. 다크모드 (Dark Mode) 추가
- `App.tsx` 최상위 상태에 `isDarkMode` 추가 (기본값: false, LocalStorage와 연동하여 상태 유지).
- 헤더 또는 환경설정 UI에 다크모드 전환 토글 버튼 추가.
- `index.css`에 `.dark` 클래스 선택자를 정의하여 다크모드 전용 CSS 변수(배경색, 텍스트색, 테두리색 등) 적용.

### B. 그래프 마우스 호버 툴팁 추가
- `WeightChart` 컴포넌트 내의 데이터 포인트(`circle`)에 마우스 호버(`onMouseEnter`, `onMouseLeave`) 이벤트를 추가.
- 호버 시 툴팁 상태(`hoveredPoint`)를 활성화하고, 해당 점의 종합 평균 중량(예: `10.25 g`)을 말풍선(Tooltip) 형태로 표시.

### C. 레이아웃 겹침 문제 해결 및 로고 가운데 정렬
- **레이아웃 겹침 해결**: 메인 대시보드의 CSS Grid (`grid-cols-1 lg:grid-cols-3`) 대신 Flexbox 기반 (`flex flex-wrap lg:flex-nowrap gap-6 w-full`)으로 변경. 각 카드(`resizable-card`)가 리사이즈될 때 겹치지 않고 자연스럽게 아래로 떨어지거나 크기가 맞물려 배치되도록 수정.
- **로고 가운데 정렬**: 사이드바 상단 로고 컨테이너의 클래스에 `justify-center`를 추가하여 중앙 정렬 처리.

### D. 디자인시스템 테마 파란색 수정
- 브랜드 씨앗 대표색인 `--seed-color-primary` 및 `--color-primary`를 Charcoal(#1F2328)에서 이미지2의 쨍한 파란색(예: `#0000CD`)으로 수정.
- `public/brand/logo/logo-h.svg`의 텍스트 색상 클래스 `.cls-2`를 `#0000CD`로 변경하여 로고를 파란색으로 통일.

### E. 보고서 양식 세부 수정
- **싸인란(결재란)**: 서명란에 텍스트 이름(작성자/확인자)이 표시되지 않도록 빈칸으로 수정.
- **날짜칸**: 하단 날짜칸의 `/` 기호를 빈칸으로 제거.
- **좌우대칭 변경**:
  - 보고서 상단부: 왼쪽 결재란 ↔ 오른쪽 제목 위치를 대칭 전환 (제목은 왼쪽 정렬, 결재란은 오른쪽 배치).
  - 보고서 하단부: 왼쪽의 `(주)제니트리` ↔ 오른쪽의 `[JTQF-3440-05]` 위치를 대칭 전환 (왼쪽 아래에 `[JTQF-3440-05] (Rev.0)`, 오른쪽 아래에 `(주)제니트리`).

### F. 보고서 수치 미출력 해결 및 개별 분할 인쇄 연동
- **수치 출력**: 보고서 인쇄 미리보기 모달 내부에 빈 박스 안내문구 대신 실제 계측 수치가 들어간 테이블(`PrintReportTemplate`)을 보여줌.
- **개별 인쇄 분리**: 충진1, 충진2, 포장 각각 별도의 검사항목과 계측 기록이 존재하므로, 사용자가 발행할 단계를 선택하거나 각각 개별적인 A4 1페이지 형식으로 출력될 수 있게 `@media print` CSS 스타일(page-break-before/after) 및 렌더링 분기 세분화.
- **프린터 연동**: 실제 프린트물 출력 시 여백 및 크기가 A4 세로(Portrait) 규격에 완벽히 맞도록 인쇄 스타일 최적화.

## 3. 검증 계획
1. **다크모드 토글**: 다크모드 전환 시 전체 테마(배경, 텍스트, 카드 등)가 다크 컬러로 자연스럽게 바뀌는지 검증.
2. **차트 툴팁**: 중량 그래프의 각 동그라미 점에 마우스를 올렸을 때 말풍선에 올바른 평균값이 뜨는지 확인.
3. **레이아웃 반응형**: 창 크기를 줄이거나 늘려도 가려짐 현상 없이 카드가 서로 밀어내며 자연스럽게 배치되는지 확인.
4. **로고 및 상단바**: 로고가 중앙 정렬되고 파란색으로 칠해지는지 확인.
5. **보고서 수정사항**: 결재란의 이름 제거, 날짜칸 `/` 제거, 제목-결재란 위치 대칭, 하단 푸터 위치 대칭, 실 수치 정상 렌더링 여부 검증.
6. **프린트 출력**: 프린트 미리보기 및 인쇄 시 충진1, 충진2, 포장 데이터가 각각 A4 영역에 맞춰 독립적으로 프린트되는지 브라우저 인쇄 모드 검증.
