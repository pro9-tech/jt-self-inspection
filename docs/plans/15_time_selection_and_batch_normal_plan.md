# 15. 계측 테이블 시간 선택 UI 및 일괄정상/해제 복원 구현 계획서

## 1. 개요 및 목적
- **목적**:
  1. 실시간 한국 시각 입력 방식을 다시 정적 시간 포맷(`'09:00'`, `'10:00'` 등)으로 변경.
  2. 첫 번째 행의 시간은 `'09:00'` ~ `'17:00'` 중에서 드롭다운으로 선택할 수 있도록 구현.
  3. 두 번째 행부터는 첫 번째 행의 시간 기준으로 1시간 단위(+1 hour)로 자동 계산되어 입력되도록 구현.
  4. '일괄정상' 버튼을 테이블 헤더(기존 위치)에 복원:
     - 누르면 행들이 즉시 정상 데이터로 채워지고, 다음 행 생성 시에도 정상 데이터가 미리 입력되어 나타남.
     - '일괄정상'을 누르면 버튼이 '일괄정상해제'로 변경됨.
     - '일괄정상해제'를 누르면 모든 일괄 정상 입력된 칸이 중량칸은 `'0.0'`(null), 나머지 상태는 `'선택'`(null)으로 복귀되고 버튼도 다시 '일괄정상'으로 원복됨.
  5. 기존에 완성된 유효성 검사(All-or-Nothing, 빨간 테두리, 메모장 선 강조) 및 모든 클라우드 연동(구글 시트, Supabase) 100% 유지.

---

## 2. 세부 구현 사양

### A. 시간 표시 및 1시간 단위 자동 증가
1. **첫 번째 행 (`isFirstRow: true`)**:
   - 미저장 상태(`!isSaved`): 드롭다운 선택 상자(`09:00` ~ `17:00`) 제공.
   - 시간 변경 시, 해당 값으로 첫 행 시간이 변경되며 이후 연결된 행들의 시간도 1시간 단위로 자동 갱신.
   - 저장 완료(`isSaved`): 텍스트로 시간 표시.
2. **두 번째 행 이후 (`isFirstRow: false`)**:
   - 상위 행 시간 기준으로 1시간 자동 계산된 텍스트 표시.
3. **행 저장 버튼 (`handleSaveClick`)**:
   - 실시간 한국 시간 덮어쓰기 로직 제거 ➔ 행에 부여된 시간(`measurement.time`)을 온전히 보존하여 저장(`isSaved: true`).

### B. 일괄정상 / 일괄정상해제 버튼
1. **상태 관리**:
   - `isBatchNormal: boolean` 상태를 `AppContent`에 선언 (기본값: `false`).
2. **'일괄정상' 클릭 시**:
   - `setIsBatchNormal(true)`.
   - 현재 테이블의 모든 행의 `vials`를 `standardWeight`로, 상태 토글을 `'정상'`으로 일괄 채움.
   - 버튼 라벨이 `'일괄정상해제'`로 변경.
3. **'일괄정상해제' 클릭 시**:
   - `setIsBatchNormal(false)`.
   - 모든 행의 `vials`를 `[null, null, null]`로, 상태 토글을 `[null, null, null]`로 초기화 (중량은 `0.0`, 상태는 `선택`으로 복귀).
   - 버튼 라벨이 `'일괄정상'`으로 복귀.
4. **새 행 생성 (`onSaveRow`) 시**:
   - `isBatchNormal`이 `true`이면 새로 생기는 행에 정상 데이터가 미리 입력되어 생성됨.
   - `isBatchNormal`이 `false`이면 빈칸(`null`)으로 생성됨.

## 3. 검증 계획
- `npm run build`를 통한 빌드 및 타입 무결성 검증.
- 첫 행 시간 변경 시 후속 행 시간 연동 확인.
- 일괄정상 클릭 시 정상값 입력 ➔ 새 행 생성 시 정상값 유지 확인.
- 일괄정상해제 클릭 시 초기화(0.0 / 선택) 확인.
