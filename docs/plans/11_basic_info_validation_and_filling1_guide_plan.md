# [구현 계획서] 기본 정보 설정 필수 입력 검증 및 충진1 중량 수치 안내문 추가

## 1. 개요
체이스의 요청에 따라 자주측정 앱의 입력 편의성 및 데이터 정확도를 높이기 위해 두 가지 기능을 구현합니다:
1. **기본 정보 설정 필수 검증**: '기본 정보 설정' 카드 내의 항목 중 하나라도 입력되지 않은 경우, 저장(`저장` 버튼 클릭)이 불가능하도록 차단하고 미입력 칸을 빨간색 테두리/배경으로 강조 표시합니다. (계측 테이블 기록은 검증 제외)
2. **충진1 전용 수치 안내문 추가**: '계측 테이블 기록' 카드 내 '일괄정상' 버튼 바로 아래에 한 줄로 수치를 명확히 재확인할 수 있는 안내문을 추가합니다. (중량미달 수치는 **빨간색**, 중량초과 수치는 **파란색**)

---

## 2. 세부 구현 내용

### 가. 기본 정보 설정 필수 입력 검증 (Validation)
- **상태 관리**: `validationErrors` 상태(`Record<string, boolean>`)를 도입하여 미입력 항목을 추적합니다.
- **검증 대상 항목**:
  - `itemName` (품목명)
  - `lotNumber` (로트번호)
  - `fillingDate` (충진일 / 포장일)
  - `verifier` (측정자)
  - `operator` (확인자)
  - **[충진1 모드 전용 추가]**: `standardWeight` (정식중량), `underweightTolerance` (중량미달 허용치), `overweightTolerance` (중량초과 허용치)
- **검증 시점 및 수용 방식**:
  - 사용자가 `저장` 버튼 클릭 시 `saveRecord` 함수에서 전체 검증을 수행합니다.
  - 미입력 항목이 존재할 경우 `setValidationErrors`를 통해 빨간색 스타일 클래스를 적용하고 저장 실행을 중단(`return`)하며 알림 팝업을 표시합니다.
  - 사용자가 값을 입력/선택하면 해당 입력란의 오류 스타일이 즉시 해제됩니다.
- **계측 테이블 기록 독립성 보장**:
  - '계측 테이블 기록'의 시료 데이터(`measurements`) 입력 여부는 저장 검증에 영향을 주지 않도록 철저히 분리합니다.

### 나. 충진1 전용 중량 기준 수치 한 줄 안내문
- **위치**: 계측 테이블 기록 카드의 헤더 바('일괄정상' 버튼 포함 줄) 바로 아래 한 줄 전용 영역
- **표시 조건**: `record.mainMode === '충진' && record.subMode === '충진1'`일 때만 한 줄로 노출
- **디자인 스타일**:
  - 한 줄 배치 (Flex/Wrap 대응)
  - **중량미달 수치**: 빨간색 글씨 (`text-red-500 font-black`)로 한계 수치(예: `9.8g 이하 (±0.2g)`) 표시
  - **중량초과 수치**: 파란색 글씨 (`text-blue-500 font-black`)로 한계 수치(예: `10.2g 이상 (±0.2g)`) 표시
  - 기존 디자인 시스템(ZT/Tailwind dark:mode 대응) 완벽 준수

## 3. 진행 단계
1. **[계획서 아티팩트 전달]**: 구현 계획을 작성하고 체이스에게 전달
2. **[사용자 동의 확인]**: 체이스의 승인 후 코드 작성 시작
3. **[코드 작성 및 검증]**: `src/App.tsx` 수정 적용 후 비효율성/문법 오류 검증
4. **[결과 보고 및 설명]**: 체이스에게 초보자 눈높이 맞춤으로 자세히 설명
