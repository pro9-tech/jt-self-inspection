# 16. 계측 테이블 시간 점심시간(13:00) 제외 및 12:00 -> 14:00 건너뛰기 계획서

## 1. 개요 및 목적
- **목적**:
  1. 첫 번째 행의 시간 선택 드롭다운에서 `'13:00'`(점심시간) 제외.
  2. 행이 추가되거나 첫 행 시간 변경으로 후속 행 시간이 계산될 때, `'12:00'` 다음 시간은 `'13:00'`이 아닌 바로 `'14:00'`으로 건너뛰도록 처리.
  3. 기존의 모든 연동, 유효성 검사, 디자인 시스템 완벽 유지.

---

## 2. 세부 변경 사항
1. **시간 선택 옵션 리스트**:
   - `['09:00', '10:00', '11:00', '12:00', '14:00', '15:00', '16:00', '17:00']` (13:00 제외)
2. **시간 증가 로직**:
   - 다음 시간 계산 시 `nextH === 13`인 경우 `nextH = 14`로 점프.
3. **적용 위치**:
   - `MeasurementRow` 내 select 옵션 목록
   - `handleFirstRowTimeChange` 함수
   - `onSaveRow` 함수 (새 행 추가 시 시간 계산)
