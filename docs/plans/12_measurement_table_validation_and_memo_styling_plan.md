# 12. 계측 테이블 유효성 검사 및 메모장 테두리 스타일 개선 계획서

## 1. 개요 및 목적
- **목적**:
  1. 계측 테이블에서 부적합 상태임에도 메모를 작성하지 않고 저장 시, 메모장 행과 중간 세로 구분선까지 모두 빨간색 테두리로 강조 표시.
  2. 최소 한 항목의 3개 측정값을 채우지 않고 저장 시도 시 저장을 거부하고, 메모장은 펼치지 않은 채 해당 줄 전체를 빨간색 테두리로 표시. (단, 한 항목만이라도 3개가 채워지면 다른 항목은 비어있어도 저장 허용)
  3. 기존 데이터 연동(구글 시트, Supabase) 및 UI 디자인 시스템 완벽 유지.

---

## 2. 세부 요구사항 분석
1. **부적합 메모 누락 저장 거부 (Memo Error)**
   - 항목 중 판정이 "부적합"인 항목이 있으나 해당 항목의 메모가 미작성된 경우 저장 거부.
   - 본문 행(`<tr>`) 전체 테두리 및 세로선 빨간색 표시.
   - 메모장 행(`<motion.tr>`)을 펼침(`isExpanded: true`).
   - 펼쳐진 메모장 행의 모든 테두리(상/하/좌/우)와 내부 중간 세로 구분선들(`border-l-2`, `border-r-2`)을 빨간색(`border-red-500`)으로 표시.

2. **최소 한 항목 3개 선택 미완료 저장 거부 (Incomplete Error)**
   - 모드별 측정 항목:
     - **충진1**: 중량(3개), 캡(3개)
     - **충진2**: 스티커(3개), 날인(3개)
     - **포장**: 날인(3개), 캡(3개), 스티커(3개), 스크래치(3개), 이물(3개)
   - 위 항목들 중 **단 하나라도 3개가 온전히 입력/선택된 항목**이 있다면 통과 (다른 항목이 비어있어도 무관).
   - 모든 항목이 3개를 채우지 못한 경우(0~2개 선택 등) 저장 거부.
   - **메모장은 펼치지 않음** (닫힌 상태 유지).
   - 해당 행의 모든 선(외곽선 및 세로 구분선)을 빨간색(`border-red-500`)으로 표시.

3. **정상 저장 통과 조건**
   - 최소 한 항목 이상 3개 선택 완료 **AND** 모든 부적합 항목에 대한 메모 작성 완료.
   - 실시간 한국 시간(HH:mm) 기록 및 저장 완료 플래그(`isSaved: true`, `isExpanded: false`) 설정.
   - 다음 행 자동 생성 트리거(`onSaveRow`) 정상 호출.

## 3. 구현 단계
1. **유효성 검사 헬퍼 함수 (`isCategoryComplete`) 추가**:
   - 3개 요소가 모두 존재하는지(null/빈값 제외) 판별.
2. **`handleSaveClick` 저장 유효성 로직 분기**:
   - Step 1: 최소 1개 항목 3개 입력 여부 확인 -> 미달 시 `setShowError(true)`, 메모장 열지 않고 중단.
   - Step 2: 부적합 판정 항목의 메모 입력 여부 확인 -> 누락 시 `setShowError(true)`, `isExpanded: true`로 메모장 열고 중단.
   - Step 3: 모두 통과 시 `setShowError(false)`, 저장 및 다음 행 생성.
3. **테이블 셀 및 메모장 셀 CSS 테두리 동적 처리**:
   - 본문 행 `<tr>` 및 각 `<td>`의 상/하/좌/우/구분선에 `showError` 시 `border-red-500` 적용.
   - 메모장 행 `<motion.tr>` 및 각 `<td>`의 상/하/좌/우/구분선에 `showError` 시 `border-red-500` 적용.
4. **검증 및 빌드 테스트**:
   - `npm run build`를 통해 문법 오류 및 타입 에러가 없는지 최종 확인.
