# 모바일 헤더 및 차트 간소화 구현 계획서

모바일 화면 상단의 브랜드 로고 크기를 최적화하고, 제목을 가운데 정렬된 두 줄 형태로 개편하며, 차트 내 상세 모드(평균/개별/범위) 전환 탭을 제거하여 UI를 직관적으로 간소화하기 위한 계획입니다.

## 1. 개요 및 배경
- **모바일 헤더 리팩터링**: 
  - 모바일 기기(768px 이하) 접속 시 상단 헤더에 들어간 로고 마크가 지나치게 영역을 많이 차지하는 현상을 개선하기 위해 높이 및 너비를 문장 두 줄 분량 크기(`h-10 w-10`)로 조절합니다.
  - 헤더의 제목 텍스트를 첫 번째 줄 "충진품 자주측정", 두 번째 줄 "(충진)" 혹은 "(포장)" 형식으로 나누어 가운데 정렬하여 가독성과 균형감을 높입니다.
- **차트 옵션 탭 제거**:
  - 차트 조작부에서 꺾은선 그래프일 때 제공하던 `평균`, `개별`, `범위` 선택 버튼들을 완전히 삭제합니다.
  - 꺾은선 그래프 모드는 기본인 **평균 트렌드** 꺾은선 차트로 작동을 고정하여, 사용자가 혼선 없이 차트를 감상할 수 있도록 처리합니다.

## 2. 주요 변경 사항 및 사양

### [src/App.tsx](file:///c:/Users/janytree/OneDrive/바탕%20화면/jt-self-inspection/src/App.tsx)

#### A. 모바일 전용 상단 헤더 바 레이아웃 개편
- 모바일 전용 헤더 바를 3단 Flex 구조로 개편합니다:
  - **좌측**: 로고 마크 (`h-10 w-10`) 배치.
  - **중앙**: `flex-1 text-center` 스타일의 컨테이너를 배치하고, 제목("충진품 자주측정")과 모드명("({record.mainMode})")을 상하 2줄 구조로 렌더링.
  - **우측**: 분류 모드 토글 탭 및 관리자 자물쇠 버튼을 그룹화하여 조밀하게 정렬.

#### B. `WeightChart` 상세 분석 탭 제거 및 모드 고정
- `WeightChart` 컴포넌트 내의 상태 전환 버튼 렌더링 영역에서 상세 분석 모드(`chartMode === 'average' | 'individual' | 'minMax'`)를 고르는 세그먼트 버튼 렌더링 코드 전체를 **삭제**합니다.
- `WeightChart` 컴포넌트가 마운트되거나 꺾은선 차트가 그려질 때는 디폴트 상태인 `'average'` (평균 트렌드) 꺾은선 차트로만 기능하도록 코드를 정리합니다.

## 3. 검증 계획
1. **모바일 뷰포트 헤더 검증**:
   - 모바일 해상도(width <= 768px)에서 상단 로고의 크기가 문장 두 줄 높이에 상응하게 적절히 줄어들었는지 확인합니다.
   - 제목 텍스트가 첫 줄 "충진품 자주측정", 둘째 줄 "(충진)" 혹은 "(포장)"으로 나뉘어 화면 중앙에 정확히 가운데 정렬되는지 확인합니다.
2. **차트 상세 탭 제거 검증**:
   - 대시보드의 중량 트렌드 그래프 우상단에서 기존의 `평균`, `개별`, `범위` 버튼들이 완전히 사라졌는지 확인합니다.
   - 꺾은선 차트 선택 시 기본 평균 트렌드 그래프가 누락이나 버그 없이 여전히 올바르게 렌더링되는지 확인합니다.
