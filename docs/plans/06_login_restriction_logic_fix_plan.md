# 로그인 제한 로직 수정 및 관리자 목록 확장 계획서

앱 접속 시 사용자가 로그인 버튼을 누르지도 않았는데 '로그인 제한' 팝업이 바로 노출되는 문제를 해결하고, 관리자 계정 추가 및 로그인 화면 접근성을 보장하기 위한 구현 계획입니다.

## 1. 개요 및 배경
- **현상**: 이전에 로그인되어 있던 구글 세션 정보가 브라우저에 남아 있는 상태로 접속 시, `App.tsx` 마운트 시점에 파이어베이스 자동 로그인(`onAuthStateChanged`)이 발생하고, 해당 계정이 등록된 사용자 목록에 없으면 즉시 차단 팝업이 노출되며 강제 세션 클리어가 일어납니다. 이로 인해 사용자가 로그인 화면으로 진입하여 다른 계정을 선택할 수 없는 루프 상태에 빠집니다.
- **해결 방안**:
  1. `abcd7623@janytree.com` 및 `pro9@janytree.com` 두 계정을 관리자 목록에 추가합니다.
  2. 접속 시 자동으로 세션이 잡혀 권한 없음으로 판단되더라도, 조용히 로그아웃하고 세션을 초기화하여 로그인 화면을 계속 보여줍니다.
  3. 오직 로그인 화면에서 사용자가 **[구글 로그인]** 버튼을 직접 누른 직후에만 권한 검사 실패 시 차단 팝업이 노출되도록 제어하여, 사용자가 이메일을 다시 선택할 수 있는 기회를 보장합니다.

## 2. 주요 변경 예정 파일

### [src/App.tsx](file:///c:/Users/janytree/OneDrive/바탕%20화면/jt-self-inspection/src/App.tsx)

#### A. 관리자 이메일 상수 정의 및 하드코딩 제거
- 관리자 계정 판단을 위해 다음의 상수를 정의합니다:
  ```typescript
  const ADMIN_EMAILS = ['pro9@janytree.com', 'abcd7623@janytree.com'];
  ```
- 기존 `user?.email === 'pro9@janytree.com'` 등 하드코딩된 비교문을 모두 `ADMIN_EMAILS.includes(email)` 조건으로 변경합니다.

#### B. 로그인 시도 마커 설정 (`sessionStorage` 활용)
- [구글 로그인] 버튼 클릭 핸들러인 `handleLogin` 진입 시 `sessionStorage.setItem('jt_is_logging_in', 'true')`를 심습니다.
- 로그인 성공 시점에는 해당 세션을 제거합니다.

#### C. `onAuthStateChanged` 권한 검사 조건 변경
- `u`가 감지되었을 때:
  - **관리자 계정인 경우 (`ADMIN_EMAILS`에 포함)**: 무조건 통과시키며, 만약 Firestore `settings/global`의 `operators` 및 `verifiers` 목록에 현재 이메일이 누락된 경우, 자동으로 항목을 추가해 주는 안전 마이그레이션 로직을 실행합니다.
  - **일반 계정인 경우**: Firestore에 등록된 이메일이 있는지 확인합니다.
    - 허용된 경우: 정상 로그인 처리 및 `jt_is_logging_in` 마커 제거.
    - 허용되지 않은 경우:
      - `sessionStorage.getItem('jt_is_logging_in') === 'true'` (로그인 버튼을 직접 누른 경우) 이면 기존처럼 차단 팝업을 띄우고 세션을 지웁니다.
      - 그렇지 않은 경우 (접속 시 자동 로그인된 경우) 팝업을 띄우지 않고 **조용히 로그아웃(`signOut`) 및 세션 초기화** 후 로그인 화면으로 돌아가게 만듭니다.

## 3. 검증 계획
1. **앱 접속 시 무한 차단 루프 탈출 검증**:
   - 권한이 없는 계정으로 로그인되어 있는 환경에서 앱에 새로 접속하더라도 바로 차단 팝업이 뜨지 않고 로그인 화면이 정상적으로 출력되는지 확인합니다.
2. **관리자 계정(abcd7623@janytree.com, pro9@janytree.com) 권한 확인**:
   - 두 계정으로 로그인했을 때 정상 진입되며, 환경설정 아이콘 옆 자물쇠가 정상적으로 보이는지 검증합니다.
   - 두 관리자 계정이 Firestore `settings/global` 내 측정자/확인자 목록에 자동으로 주입되어 렌더링되는지 확인합니다.
3. **권한 없는 계정 로그인 시 차단 팝업 정상 작동 검증**:
   - 로그인 화면에서 등록되지 않은 다른 구글 계정으로 로그인을 시도했을 때, 기존과 동일하게 "로그인 제한" 팝업이 알맞은 안내 문구와 함께 노출되는지 확인합니다.
